Release date: 2026-07-28

New

  • Organize: sort a folder and name every file in one pass. Select files or a folder and NameQuick sorts everything into clear folders and gives each file a clear name from your naming setup. You see the estimated cost before it runs and approve the plan before anything moves, names appear live while it works, and any file NameQuick cannot place confidently goes to Review instead of being guessed.
  • Choose what names Organize uses. In Settings → Processing, pick Smart Rename, a saved prompt, or one of your naming templates.
  • Organize runs on cloud AI. Use your subscription or your own API key. Local models are not supported for Organize yet; renaming still works with a local model.

Improvements

  • Honest credit receipts. After a run, NameQuick shows exactly what it used against what you approved, like “Used 24 of 40 approved.”
  • See what an estimate is made of. Hover an estimate to get the breakdown behind the number.
  • No limit on how big a run can be. The cap on files per run is gone. You approve the cost up front, so you decide the size of the run.
  • Faster naming. Files are named in parallel and results appear as they are ready, so batches finish sooner and you can watch progress instead of waiting.

Bug Fixes

  • Fixed an issue where sorting could fail to suggest folders. Some document batches ended a run without a folder plan. Organize now produces suggestions reliably for these batches.
  • Fixed declined plans leaving files marked ready to move. When you decline a plan or a run cannot finish, nothing is left queued as approved.
