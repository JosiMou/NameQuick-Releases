Release date: 2026-08-08

New

Improvements

  • Cloud API keys are checked before you rely on them. Adding a key now runs a quick test request, so a key without credit or billing set up tells you right away what to fix instead of failing on every rename later.
  • Clearer status for automatically adjusted names. When NameQuick adds a counter or shortens a name to avoid a conflict, the file now appears as successfully Adjusted in the list, grid, and inspector instead of incorrectly asking for review.

Bug Fixes

  • Fixed purchases being reported as failed while you were still checking out. Taking your time in the browser no longer causes NameQuick to give up on the purchase or trial. The app now waits for checkout to finish before it starts counting.
  • Fixed upgrades failing without any message. If activation cannot complete after a purchase, NameQuick now says so clearly and gives you a way to try again.
  • Fixed a stopped local AI server failing your whole batch. When LM Studio or Ollama stops responding partway through, remaining files now wait and continue once the provider is back, and messages tell you whether the server is offline, the model is not loaded, or the model is missing.
  • Fixed Stop allowing the rest of a batch to continue. Stopping Smart Rename now cancels the current run and prevents remaining queued files from starting.
  • Fixed brief Managed AI interruptions failing files immediately. NameQuick now retries temporary service errors and offers Rerun if the service is still unavailable.
  • Fixed the first pass of a Watch Folder using the toolbar’s naming option. Files already in a newly added folder now use the preset selected for that folder.
  • Fixed cloud Watch Folders getting stuck after a partial scan. NameQuick now keeps indexing the files it can read while protecting files in temporarily unavailable locations, so one unavailable path no longer freezes the whole folder.
  • Fixed cloud-file renames showing a name that was not actually applied. NameQuick now verifies the result on disk and keeps the file list and History aligned if a storage provider delays or reverses a rename.
  • Fixed repeated notification permission prompts. NameQuick no longer asks again after you decline, and Settings shows declined notifications as a choice rather than an error.
