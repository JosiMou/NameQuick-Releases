Release date: 2026-07-31

New

Improvements

  • More reliable MLX model downloads. Long downloads stay active while NameQuick is running, temporary service errors retry automatically, and failures now explain whether storage, network access, or the selected model needs attention.

Bug Fixes

  • Fixed MLX getting stuck after a model failed to load. Check again now attempts to load the model instead of returning to the same blocked state, with a reinstall option when needed.
  • Fixed readable API keys being reported as locked. NameQuick now checks the selected provider key directly, preventing false keychain warnings from pausing otherwise ready batches.
