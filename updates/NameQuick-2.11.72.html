Release date: 2026-07-31

Improvements

  • See when a rule only partly applies. If a rename succeeds but a matched rule cannot complete every action, NameQuick now marks the file as Partly applied and explains what needs attention.

Bug Fixes

  • Fixed rules being skipped after some renames. Finder tags, comments, color labels, and file dates now apply when you approve a file in Review or use Quick Rename. Reviewed files with edited names also move to the rule’s destination folder.
  • Fixed valid dates and identifiers being mistaken for file paths. Document values that contain a slash, such as dates or business identifiers, no longer block the rename.
  • Fixed downloaded local models becoming impossible to remove. Models on your Mac remain manageable in AI settings after you switch providers, and you can remove the active model after confirming that another AI will be needed for renaming.
