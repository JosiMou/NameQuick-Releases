Release date: 2026-08-21

New

Improvements

  • More resilient Watch Folders after network shares reconnect. If macOS remounts the same share under a different name, NameQuick now reconnects the Watch Folder and keeps its library entries and automation in place.

Bug Fixes

  • Fixed Watch Folders applying the wrong naming instructions. Files processed again now keep the folder’s assigned Smart Rename or custom prompt setting instead of falling back to a different naming setup.
  • Fixed repeated processing after NameQuick renames files on network shares. Watch Folders now recognize completed renames even when SMB cannot provide the usual file identity details.
