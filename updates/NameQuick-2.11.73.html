Release date: 2026-08-04

New

  • Introducing cloud-storage Watch Folders. Add folders directly from connected iCloud Drive, Dropbox, Google Drive, OneDrive, or Box locations. NameQuick shows each available service by name, so you can start in the right place without browsing through system folders.
  • Choose what happens to files already in a large Watch Folder. NameQuick counts supported files without downloading them, then lets you rename everything, limit the first pass to files changed in the last 30 days, 90 days, or 12 months, or start with new files only. Expected downloads and Managed AI credit use, when applicable, are shown before you decide.

Improvements

  • Cloud files stay online until they are needed. Adding and indexing a cloud folder no longer downloads every online-only file. NameQuick keeps placeholders visible and downloads content when it processes a file for renaming.
  • Duplicate Detection now identifies online-only files it has not checked. NameQuick keeps these files visible and lets you choose when to download and scan them instead of treating an unchecked cloud folder as duplicate-free.
  • Better local model recommendations for your Mac. NameQuick now bases fit labels on measured memory and prioritizes the strongest runnable option, helping you avoid both oversized models and unnecessarily weak recommendations.
  • See how long a local model download may take. Stable time estimates now appear after enough progress data is available, and NameQuick explains that the first rename can take longer while the model loads.
  • Clearer AI readiness and recovery. The main rename area now explains when a local model, API key, Keychain access, provider connection, or model choice is blocking renaming and shows the relevant fix. Where available, you can explicitly switch to a configured alternative provider.
  • More useful local AI accuracy guidance. Before an affected local run, NameQuick now warns when scanned PDFs may be less accurate or exceed the configured page limit. The notice describes only the current batch and can be dismissed for the session.
  • Immediate feedback for AI recovery actions. Starting or checking a provider, installing a runtime, loading a model, and repairing local AI now show progress as soon as you click. Model downloads keep one clear progress state with Cancel.
  • Clearer Watch Folder names. Cloud roots and progress messages now use familiar names such as iCloud Drive instead of system directory names.

Bug Fixes

  • Fixed Watch Folders using the wrong naming option. Automatic renames now consistently use the preset selected for the folder instead of sometimes falling back to Smart Rename.
  • Fixed Watch Folder files being lost when Managed AI credits run out. Files now wait with an Out of credits status and resume after the balance is refreshed instead of being marked as failed.
  • Fixed Undo leaving rule changes behind. Undo now restores Finder tags, comments, and file dates changed by a post-rename rule, along with the original filename and location.
  • Fixed AI refusal messages becoming filenames. Replies with typographic apostrophes are now recognized as refusals instead of being applied as filenames.
  • Fixed Managed AI failures for XML and empty Office files. XML files now use a supported format, while Office documents with no readable text show a clear error instead of sending an unusable file.
  • Fixed rejected API keys still appearing ready. If a provider rejects your configured key during a rename, NameQuick now updates its status and shows the appropriate recovery action instead of keeping the old verified state.
  • Fixed local model downloads continuing after switching providers. NameQuick now stops a queued or active model download after you leave that local provider during setup.
  • Fixed cancelled runs being reported as failures. Stopping a run no longer displays a cancellation error or records the run as failed.
  • Fixed some rename conflicts and access errors using the wrong status. These errors now show the correct icon, recovery action, and dismissal behavior in every supported language.
