Release date: 2026-08-15

New

  • Review unavailable files in one place. NameQuick now gathers files it can no longer find into a focused list, where you can check them again or remove their library entries without deleting anything from your Mac.

Improvements

  • Watch Folder problems no longer fail silently. If file indexing cannot start, NameQuick now explains that Watch Folders are not being checked and lets you try again or copy details for support.
  • Clearer status labels across the app. Queued files now use the same wording in the list and inspector, and finished suggestions are clearly marked Ready to apply.

Bug Fixes

  • Fixed completed renames being processed again. NameQuick now recognizes files it already renamed even when iCloud Drive or another synced location reports the change later or after reopening the app.
  • Fixed template separators reverting. Spaces and other separators selected between template fields now stay saved and are used when filenames are generated.
