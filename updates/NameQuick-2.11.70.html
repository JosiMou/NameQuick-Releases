Release date: 2026-07-30

New

  • Get a better starting point for photo batches. When you reject a proposed name for a batch of images in Quick Rename, NameQuick can suggest running the batch again with your Photos naming template. The new suggestions return to Review, and your saved default stays unchanged.

Improvements

  • Use less memory when MLX is idle. The built-in MLX model now unloads after five minutes by default and loads again for your next rename. Choose five minutes, fifteen minutes, one hour, or while NameQuick is open in AI settings.
  • More accurate Review progress. Review keeps showing filing progress until approved files finish, and its counts now match the files visible under the selected filter.

Bug Fixes

  • Fixed Quick Rename controls becoming hidden. The action row now stays pinned at the bottom when file lists or recovery messages fill the workspace, and its controls remain visible on macOS 26.
  • Fixed unclear out-of-credit errors when using your own API key. NameQuick now identifies exhausted provider balances, links you to the relevant billing page, and leaves unstarted files waiting instead of failing the rest of the batch one by one.
  • Fixed Organize problems disappearing from Review after folder changes. Problem items already shown in Review now remain visible after folder rescans so you can resolve them.
  • Fixed outdated Organize plans failing without an explanation. Review now tells you when an earlier run already moved a file or when the original is no longer available, with support details available when needed.
